\section{Addressable transversal T gates on good quantum LDPC codes}
\label{sec:op_f8345db004d2e958}

\paragraph{Problem.}
Can an asymptotically good qubit stabilizer code family apply a logical $T$ gate to any individual logical qubit using physical powers of $T$? Seek a family $[[n,k_n,d_n]]$ with $n\to\infty$, $\liminf_n k_n/n>0$ and $\liminf_n d_n/n>0$. The code distance $d_n$ is the least weight of a Pauli that preserves the codespace and acts nontrivially on it. Each code must have a stabilizer generating set whose maximum check weight and maximum number of checks containing a qubit are bounded by a constant independent of $n$.

Let $T=\operatorname{diag}(1,e^{i\pi/4})$. For each code, fix one encoding isometry $V_n$ for all gate choices. For every logical index $j$, require integers $b_{j,i}$ and a phase $\theta_j$ satisfying
\begin{equation}
\left(\bigotimes_{i=1}^n T^{b_{j,i}}\right)V_n
=e^{i\theta_j}V_nT_j,
\label{eq:atq-addressability}
\end{equation}
where $T_j$ acts only on logical qubit $j$. Equation~\eqref{eq:atq-addressability} specifies the entire physical gate as one tensor product.

\subsection*{Status}

Unsolved

\subsection*{Source}

Lin, Wu and Cheng pose this question in Section~6, item~2, with a fixed encoding and bounded weight and participation. Meiburg asks for the same combination of addressability, sparsity, rate and distance in Section~6 \sourcecite{ref:atq-lwc}{LWC26}, \sourcecite{ref:atq-meiburg}{Mei26}.

\subsection*{Progress}

\begin{itemize}
  \item Lin, Wu and Cheng, Theorem~4.5, construct asymptotically good binary CSS codes with fully addressable logical $T$ implemented by physical powers of $T$. The construction has no uniformly bounded check-weight and participation guarantee \sourcecite{ref:atq-lwc}{LWC26}. Wu, Lin, and Cheng improve the guaranteed rate and relative distance in Theorems~1 and~2. Uniform sparsity of Pauli checks remains open for these constructions \sourcecite{ref:atq-wlc}{WLC26}.

  \item Meiburg, Sections~4--5, obtains sparse Pauli checks with transversal $T$ at vanishing rate and a separate protected-subsystem construction with constant protected rate, distance $\Omega(\sqrt n)$, and sparse, generally non-Pauli checks \sourcecite{ref:atq-meiburg}{Mei26}.

  \item Li, Li, Han and Liu, Theorem~1.1 and Section~3.4, construct good binary quantum LDPC codes with addressable transversal logical controlled-phase gates across code blocks \sourcecite{ref:atq-llhl}{LLHL26}. Under a product-expansion hypothesis, Tan and Zhu obtain individually addressable logical CCZ gates on disjoint triples, with distance $\Omega_\epsilon(n/\log^2 n)$ in Theorem~1.2 \sourcecite{ref:atq-tz}{TZ26}.
\end{itemize}
