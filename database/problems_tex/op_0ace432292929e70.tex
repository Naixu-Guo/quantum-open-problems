\section{A 33-dimensional code correcting one error on 11 qubits}
\label{sec:op_0ace432292929e70}

\paragraph{Problem.}
Can thirty-three quantum levels be encoded in eleven qubits and exactly recovered after an arbitrary error on one unknown qubit? Let $\mathcal P_{11}=\{I,X,Y,Z\}^{\otimes 11}$, where the weight of a Pauli string counts its nonidentity factors. Seek a rank-$33$ orthogonal projector $P$ on $(\mathbb C^2)^{\otimes 11}$ such that
\begin{equation}
PEP=\frac{\operatorname{Tr}(PE)}{33}P
\qquad(E\in\mathcal P_{11},\ 1\leq\operatorname{wt}(E)\leq 2).
\label{eq:ec33-detection}
\end{equation}
Equation~\eqref{eq:ec33-detection} is the Knill--Laflamme condition for exact correction of one arbitrary single-qubit error. The projector may be any complex code subspace, and the protocol starts without shared entanglement.

\subsection*{Status}

Unsolved

\subsection*{Source}

Anglès Munné and Huber record a gap at eleven qubits and distance three in Section~4.2, Table~1. The target rank is the smallest one above the known construction \sourcecite{ref:ec33-amh}{AMH26}.

\subsection*{Progress}

\begin{itemize}
  \item The known lower bound on the maximum code dimension is $32$, and the rational certificate in Table~1 gives an unrestricted upper bound of $42$. The pure-code bound in Eq.~(40) of the same paper is $41$ \sourcecite{ref:ec33-roj}{ROJ19}, \sourcecite{ref:ec33-amh}{AMH26}. Stabilizer code dimensions are powers of two. Together with the upper bound, this makes dimension $32$ optimal among stabilizer codes. Any larger exact code contains a subcode of rank $33$ satisfying Eq.~\eqref{eq:ec33-detection}.
\end{itemize}
