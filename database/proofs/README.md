# Historical proof notes

The existing files in this directory are retained as historical sources for
catalog entries that already cite them. This directory is closed to new proof
submissions.

**Do not add new proofs, manuscripts, review notes, or verification artifacts to
this folder.** Publish new research progress as a publicly accessible archival
preprint, for example on arXiv or Zenodo. Cite its stable identifier and link in
the relevant problem's Progress section and bibliography through the normal
[contribution process](../../CONTRIBUTING.md).

Private review notes and intermediate calculations must stay out of the public
repository. See the [research progress policy](../../docs/RESEARCH_PROGRESS_POLICY.md)
for source requirements.
