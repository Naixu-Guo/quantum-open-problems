Can an asymptotically good qubit stabilizer code family apply a logical $T$ gate to any individual logical qubit using physical powers of $T$? Seek a family $[[n,k_n,d_n]]$ with $n\to\infty$, $\liminf_n k_n/n>0$ and $\liminf_n d_n/n>0$. The code distance $d_n$ is the least weight of a Pauli that preserves the codespace and acts nontrivially on it. Each code must have a stabilizer generating set whose maximum check weight and maximum number of checks containing a qubit are bounded by a constant independent of $n$.

Let $T=\operatorname{diag}(1,e^{i\pi/4})$. For each code, fix one encoding isometry $V_n$ for all gate choices. For every logical index $j$, require integers $b_{j,i}$ and a phase $\theta_j$ satisfying

$$
\left(\bigotimes_{i=1}^n T^{b_{j,i}}\right)V_n
=e^{i\theta_j}V_nT_j,
\tag{1}
$$

where $T_j$ acts only on logical qubit $j$. Equation (1) specifies the entire physical gate as one tensor product.
