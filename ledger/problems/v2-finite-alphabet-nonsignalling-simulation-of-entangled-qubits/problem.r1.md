Gisin explicitly poses finite-alphabet nonsignalling simulation, while
Brunner et al. isolate the same finiteness gap after giving a continuous-input
construction [Gis09],
[BGPS08].

## Comment

Continuous-input nonsignalling simulation is known, whereas exact simulation
by any finite-alphabet box used finitely many times is not.  The finiteness
requirement applies to both input and output alphabets and to the number of
resource uses.
