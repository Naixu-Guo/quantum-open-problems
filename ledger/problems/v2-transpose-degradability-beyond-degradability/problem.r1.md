Singh and Datta explicitly ask whether transpose-degradable channels differ
from ordinary degradable channels
[SD22].  Brádler had posed the same
strict-separation question using the earlier \lq\lq conjugate degradable\rq\rq{}
terminology [Bra15].

## Comment

No strict example and no equality theorem are known.  Complementation turns
Eq. \eqref{eq:p53-transpose-degradable} into transpose antidegradability and
Eq. \eqref{eq:p53-degradable} into ordinary antidegradability.  Consequently,
the source document's transpose-antidegradable separation question is exactly
the same existence problem, not a distinct problem.
