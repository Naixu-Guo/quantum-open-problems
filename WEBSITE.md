# QIQCOP Zoo website

The site is plain HTML, CSS, and JavaScript generated by `site/build.mjs` from
the TeX records in `database/problems/`. Mathematics is typeset in the browser
by MathJax 4 (SVG output), so every equation scales with zoom and renders the
same across browsers. Fonts come from Google Fonts with system fallbacks; the
logo uses Jost, whose letter O is a circle.

## Preview locally

```sh
node site/build.mjs
python3 -m http.server 8000 --directory dist
```

All links inside the site are relative, so `dist/` also works from a subpath
or a different domain.

## URL scheme

| URL | Content |
| --- | --- |
| `/` | Home: database statistics, one random unsolved and one random solved problem (with shuffle buttons), recent edits, method notes. |
| `/problems/` | Directory of every problem with search, status, tag, and sort filters (`?q=`, `?status=`, `?tag=`, `?sort=`). |
| `/problem/<id>/` | One problem page: statement, source, progress, comment, references, related problems, edit log, Edit/Cite/Share actions. |
| `/problem/<id>/<id>.tex` | The TeX record. |
| `/tags/` and `/tag/<slug>/` | Tag index and per-tag listings. |
| `/random/unsolved/`, `/random/solved/` | Redirect to a random problem. |
| `/about/` | Scope, status semantics, contribution guide, citation. |
| `/api/index.json`, `/api/problems/<id>.json`, `/api/tags.json` | Machine-readable records. |
| `/llms.txt`, `/sitemap.xml`, `/robots.txt` | Agent guide and crawler files. |

## Deployment

The [Pages workflow](.github/workflows/pages.yml) runs on every push to `main`
that touches `database/`, `site/`, or `scripts/`, builds `dist/`, and deploys
it with GitHub Actions. Configure the repository under **Settings → Pages →
Source: GitHub Actions**. The workflow checks out the full history so that
each page can show when its record was created and last edited.

Pull requests run the [validation workflow](.github/workflows/validate.yml),
which executes the same build into a temporary directory.

## Configuration

Edit `site/config.json` to change the site name, public URL, repository URL,
or the branch used by the Edit and history links.

## How the build works

1. `site/lib/tex.mjs` splits each record into its sections, numbers every
   labeled equation in order of appearance, converts text-mode TeX to HTML
   (quotes, dashes, accents, `\emph`, `\href`, lists, `\sourcecite`,
   `\eqref`), and leaves mathematics untouched for MathJax with an explicit
   `\tag{n}` so numbers are stable on any page.
2. `site/lib/render.mjs` produces the pages from those records.
3. `site/build.mjs` validates the set (unique IDs, file names matching IDs,
   canonical tags), computes related problems from shared tags, reads edit
   dates from git, and writes everything under `dist/`.
